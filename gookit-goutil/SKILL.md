## Quick Start

### Basic Usage

```go
package main

import (
    "github.com/gookit/goutil"
    "github.com/gookit/goutil/arrutil"
    "github.com/gookit/goutil/strutil"
    "github.com/gookit/goutil/maputil"
)

func main() {
    // Check empty values
    goutil.IsEmpty(nil)              // true
    goutil.IsEmpty("")               // true
    goutil.IsEmpty([]int{})          // true

    // Type conversion
    str := goutil.String(123)        // "123"
    num := goutil.Int("456")         // 456
    i64 := goutil.Int64("-789")      // -789

    // Array operations
    arrutil.IntsHas([]int{1, 2, 3}, 2)           // true
    arrutil.StringsHas([]string{"a", "b"}, "a")  // true

    // String operations
    strutil.Upper("hello")                        // "HELLO"
    strutil.ContainsAll("hello world", []string{"hello", "world"}) // true

    // Map operations
    maputil.GetByPath(map[string]any{
        "user": map[string]any{"name": "John"},
    }, "user.name")  // "John"
}
```

### 2. Use Type-Safe Functions

```go

// Acceptable - when working with mixed types

```

### 3. Error Handling

```go
// Always check errors for conversion functions
ints, err := arrutil.ToInt64s(strings)
if err != nil {
    // Handle error

// Use Must* functions only when sure data is valid
```

## Troubleshooting

### Common Issues

#### Issue: Import errors or "package not found"

**Solution:**
```bash
# Ensure module is downloaded
go mod download

# Or explicitly get the package
go get github.com/gookit/goutil

# Update dependencies
go mod tidy
```

#### Issue: Type conversion panics

**Solution:**
```go
// Use error-returning functions instead of Must* functions
ints, err := arrutil.ToInt64s(data)
if err != nil {
    // Handle conversion error
    log.Printf("Conversion failed: %v", err)
}

// Only use Must* when data is guaranteed valid
ints := arrutil.MustToInt64s(validatedData)
```

#### Issue: Generic function type inference fails

**Solution:**
```go
// Explicitly specify type parameters
result := arrutil.Filter[int](numbers, filterFunc)

// Or ensure input types are clear
numbers := []int{1, 2, 3}  // Not []any
result := arrutil.Filter(numbers, filterFunc)
```

#### Issue: Path separator issues on Windows

**Solution:**
```go
// Use filepath package for OS-independent paths
import "path/filepath"

path := filepath.Join("dir", "subdir", "file.txt")

// Or use fsutil helpers
fsutil.JoinPath("dir", "subdir", "file.txt")
```

#### Issue: Dump output not colored

**Solution:**
```go
// Enable color output
dump.Config.ShowColor = true

// Or check terminal support
if isatty.IsTerminal(os.Stdout.Fd()) {
    dump.Config.ShowColor = true
}
```

### Performance Tips

1. **Reuse slices when possible**
```go
// Good - reuse capacity
result := make([]int, 0, len(input))
result = arrutil.Filter(input, filterFunc)

// Avoid - creates new slice each time
result := arrutil.Filter(input, filterFunc)
```

2. **Use StringBuilder for string concatenation**
```go
import "strings"

var sb strings.Builder
for _, s := range parts {
    sb.WriteString(s)
}
result := sb.String()
```

3. **Batch operations when possible**
```go
// Better - single operation
replaced := strutil.Replaces(text, map[string]string{
    "a": "A",
    "b": "B",
    "c": "C",
})

// Avoid - multiple operations
replaced = strings.ReplaceAll(text, "a", "A")
replaced = strings.ReplaceAll(replaced, "b", "B")
replaced = strings.ReplaceAll(replaced, "c", "C")
```
